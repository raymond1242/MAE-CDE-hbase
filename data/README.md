# Dataset: `employees.csv`

A synthetic dataset of 300 employees, generated by [`src/generate_dataset.py`](../src/generate_dataset.py)
with a fixed seed (42). Running the generator again produces exactly the same file:

```bash
python3 src/generate_dataset.py            # defaults: --rows 300 --seed 42 --out data/employees.csv
```

## Why synthetic data

The assignment needs a specific schema (name, city, designation, salary) split into the `personal` and
`professional` column families. Public employee datasets either lack one of these columns (for example,
city salary datasets only cover one city) or are too small to compare cities, like the classic three-row
`emp` example. A generated dataset gives:

- the exact schema the assignment expects;
- no real personal data;
- full reproducibility;
- controlled data-quality problems, so the required "explicit handling of missing or invalid values" can
  be demonstrated.

## Data dictionary

| CSV column | HBase cell | Description |
|---|---|---|
| `row_key` | row key | `E0001` … `E0300`. Zero-padded so lexicographic order matches numeric order. |
| `name` | `personal:name` | Employee name (ASCII only, so the HBase shell prints it unescaped). |
| `city` | `personal:city` | Lima, Bogota, Santiago, Quito, Buenos Aires, Madrid (weighted 24/20/16/14/14/12%). |
| `designation` | `professional:designation` | Data Analyst, Software Engineer, Administrative Assistant, Data Scientist, Accountant, Project Manager, Director. |
| `salary` | `professional:salary` | Annual salary in USD, stored as text, like everything in HBase. |

The salary is computed as `base salary of the designation × city factor × random noise (0.85–1.20)`,
rounded to hundreds:

- Base salaries range from 24,000 (Administrative Assistant) to 95,000 (Director).
- City factors range from 0.85 (Quito) to 1.20 (Madrid).

An empty CSV field means **the cell is not written to HBase**: in HBase a missing value is an absent
cell, not an empty string.

## Injected data-quality problems (28 rows)

| Field | Problem | Rows | Example | Expected treatment |
|---|---|---|---|---|
| salary | missing (absent cell) | 8 | E0039 | excluded from salary statistics |
| salary | `N/A` | 3 | E0166 | excluded (not a number) |
| salary | `pending` | 2 | E0078 | excluded (not a number) |
| salary | negative | 2 | E0035 | excluded (not positive) |
| salary | `0` | 1 | E0241 | excluded (not positive) |
| salary | surrounding whitespace (`" 48500 "`) | 2 | E0156 | used after stripping whitespace |
| city | case/whitespace variants (`LIMA`, `' lima '`, `bogota`, `'Santiago '`) | 5 | E0029 | normalized to the canonical name |
| city | missing (absent cell) | 3 | E0159 | grouped as `UNKNOWN` |
| designation | missing (absent cell) | 2 | E0020 | grouped as `UNKNOWN` |

`python3 src/generate_dataset.py` prints the full list of affected row keys.
